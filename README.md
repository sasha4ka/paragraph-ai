# Paragraph AI 📚🤖

Интеллектуальный бот для платформы MAX, разработанный для помощи школьникам в работе с учебниками. Сервис позволяет загружать книги, формировать краткие конспекты по конкретным параграфам, проверять усвоение материала через интерактивные вопросы от нейросети через OpenRouter и готовиться к контрольным работам.

---

## 🌟 Ключевые возможности

* **📚 Управление книгами:** загрузка учебных материалов, структурированное хранение в профиле, выбор активного учебника и удаление неактуальных книг.


* **📝 Разбор параграфов:** автоматическое извлечение ключевых тезисов, дат, определений и понятий без лишней «воды».
* **🧠 Интерактивный опрос (Quiz):** генерация контрольных вопросов нейросетью по выбранному параграфу и диалоговая проверка ответов ученика.
* **🎯 Подготовка к контрольным:** выбор пула параграфов по предмету для генерации комплексной сводки и экспресс-тестирования.

## 🛠 Стек технологий

* **Язык разработки:** Python 3.12+
* **Пакетный менеджер:** [uv](https://github.com/astral-sh/uv?utm_source=gemini)
* **Фреймворк бота:** `maxapi`
* **База данных:** PostgreSQL
* **ORM и драйвер:** `SQLAlchemy` (асинхронный движок) + `asyncpg`
* **LLM-интеграция:** RouterAI через официальный клиент `openai`
* **Конфигурация:** `pydantic-settings`

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/sasha4ka/paragraph-ai.git
cd paragraph-ai

```

### 2. Синхронизация окружения через uv

Убедитесь, что у вас установлен `uv`. Для создания виртуального окружения и установки всех зависимостей выполните:

```bash
uv sync

```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующими параметрами:

```env
# Бот MAX
API_TOKEN=your_maxapi_token_here
DEBUG=False
WEBHOOK_URL=https://bot.example.com/webhook
# Необязательно: тот же секрет будет использован при регистрации webhook в MAX.
WEBHOOK_SECRET=your_webhook_secret

# RouterAI через OpenAI-совместимый API
OPENAI_API_TOKEN=your_routerai_key_here
OPENAI_BASE_URL=https://routerai.ru/api/v1
DEFAULT_MODEL=openai/gpt-6-luna
PARSING_MODEL=deepseek/deepseek-v4.1-flash

```

### 4. Запуск бота

Запустите проект с помощью команды `uv`:

```bash
uv run python main.py

```

### Запуск через Docker Compose

Создайте `.env` с настройками приложения и добавьте `DOMAIN=bot.example.com` для
публичного домена. Укажите DNS-запись домена на сервер и откройте порты 80 и 443.
Для локального запуска без домена Caddy использует `localhost`.

```bash
docker compose pull
docker compose up -d
docker compose logs -f app
```

По умолчанию Compose загружает образ `ghcr.io/sasha4ka/paragraph-ai:latest`.
Чтобы выбрать другой тег, задайте `IMAGE_TAG` в окружении, например `IMAGE_TAG=release`.

В обычном режиме (`DEBUG=False`, значение по умолчанию) приложение запускает
FastAPI и регистрирует `WEBHOOK_URL` в MAX. URL должен быть публичным HTTPS-адресом
и оканчиваться на `/webhook`. `WEBHOOK_SECRET` необязателен; если он задан,
приложение проверяет секретный заголовок MAX.

Для локальной разработки задайте `DEBUG=True`: приложение переключится на long
polling и удалит подписки webhook, которые мешают polling. `WEBHOOK_URL` в этом
режиме не требуется. Не используйте этот режим одновременно с production-инстансом
того же бота.
Каталог `books/` исключён из образа; загружайте книги через бота — они хранятся
в Docker volume `books_data` и переживают пересоздание контейнера.
